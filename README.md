# Sales Dashboard

## Project Overview
An interactive Sales Dashboard created using Microsoft Excel to analyze sales and profit performance.

## Tools Used
- Microsoft Excel
- Excel Tables
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas

## Dashboard Features
- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Sales by Department
- Profit by Department
- Interactive filters for Department, Category, and Region

## Dataset
The project contains 20 sales transactions with information such as:
- Order ID
- Date
- Employee
- Department
- Product
- Category
- Quantity
- Sales
- Profit
- Region

## Key Results
- Total Sales: ₹815,000
- Total Profit: ₹130,200
- Total Quantity: 100
- Total Orders: 20

## Project Purpose
This project was created as part of my Data Analyst learning journey to practice Excel data analysis, PivotTables, PivotCharts, and dashboard creation.
